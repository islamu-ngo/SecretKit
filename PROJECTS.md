# Projects

Core owns read contracts, references, bounded outcomes and independently owned
material. Infisical and AzureKeyVault own native provider operations. Their
Management packages are optional administrative planes. Extensions.Configuration
owns acquired generations and explicit string export; Extensions.Hosting owns
explicitly started authentication maintenance.

All projects target net10.0. Tests, samples and tools are non-packable. The
operation registry separates admitted, implemented and remotely verified support.
The seven-package family is under construction, not a completed release.
