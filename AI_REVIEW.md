# Review checklist

Review authority binding, endpoint escape, serialization/diagnostic disclosure,
disposal races, cancellation and uncertain mutation replay through public seams.
Check declared capability depth against the actual operation registry and tests.
Keep administrative visibility distinct from intended-identity delivery.
Verify independent package installation and host-owned transport lifetimes.
Check generation retirement, expiry, consumed-bootstrap recovery and late-disable
races. Report unrun remote/edition/platform evidence explicitly.
